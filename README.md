## English

Qurio Cell Viewer is a free, read-only Windows application for viewing large CSV, TSV, LOG, and TXT files in a spreadsheet-like interface.

Explore huge files, search for data, split structured logs into columns, and inspect long or multiline cell contents in a dedicated lower pane.

### Key Features

#### 1. View Extremely Large Files

Qurio Cell Viewer is designed to handle very large files.

**Real-file opening and display tests:**

| File type | File size | Rows |
|---|---:|---:|
| CSV | 124 GB | 2 billion |
| LOG | 500 GB | Approx. 5.7 billion |

These figures represent actual file-opening and display tests, not virtual row expansion. Search and column-splitting features were also tested using files of other sizes.

#### 2. Search Large Files

- Search for text in cells
- Regular expression, whole-word, and case-sensitive search options
- Search within a specified row range
- Navigate between search results

#### 3. Split Structured LOG / TXT Files into Columns

Make structured logs easier to read by splitting their contents into columns.

- Split using specified text delimiters
- Split using fixed character lengths
- Show or hide columns
- Adjust column widths

#### 4. Read Long and Multiline Cell Contents

Select a cell to view its contents in the dedicated lower pane.

- Display long text without relying on narrow grid columns
- View multiline text with line numbers
- Enable or disable text wrapping
- Inspect cell information and text position

### Additional Features

- Horizontal and vertical split views
- Row and column freezing
- Adjustable display zoom and font settings
- Japanese and English user interfaces
- CSV / TSV file splitting and merging
- Print preview and printing

### 主な特徴

#### 1. 巨大なファイルを閲覧

実ファイルを使用した表示検証実績：

| ファイル形式 | サイズ | 行数 |
|---|---:|---:|
| CSV | 124GB | 20億行 |
| LOG | 500GB | 約57億行 |

これらは仮想拡張ではなく、実ファイルの読み込み・表示検証結果です。検索や列分割などの操作は、別のファイルサイズ・行数でも検証しています。

#### 2. 大容量ファイルの検索

- セル内の文字列検索
- 正規表現・単語単位・大文字小文字の区別
- 行範囲を指定した検索
- 検索結果間の移動

#### 3. LOG / TXTを規則性に応じて列分割

- 指定した文字列を区切りとして分割
- 固定文字数で分割
- 列の表示・非表示
- 列幅の調整

#### 4. 横長・改行を含むセルも見やすく表示

- 選択セルの内容を下ペインに表示
- 長文・複数行テキストの閲覧
- 行番号表示と折り返し切り替え
- 文字数や位置情報の確認

### その他の機能

- 上下・左右の画面分割
- 先頭行・先頭列の固定
- 表示倍率・フォント設定
- 日本語・英語の画面表示
- CSV / TSVのファイル分割・結合
- 印刷プレビュー・印刷
